AUTORIZADO · ÉTICO COMPROMISO COMPLETO DE INFRAESTRUCTURA

Auditoría de seguridad ofensiva interna

Pentest solicitado por dirección técnica sobre servidores productivos con Docker. Nombres de host, rutas e identidad del cliente omitidos por confidencialidad corporativa — se documenta únicamente la cadena de explotación.

01

TOCTOU — symlink injection

Carrera contra un script sudo NOPASSWD de Docker Compose → persistencia root vía /etc/sudoers.

02

Git-config poisoning

Abuso de core.fsmonitor en un wrapper de git pull ejecutado como root → shell con bit SUID persistente.

03

Python library hijacking

Troyanización de yaml.py ejecutada con privilegios root → pivote a PostgreSQL y escalación a admin de Django evadiendo 2FA.
